# LIO 前端增强设计 —— 腿/轮里程计融合 + 退化场景鲁棒性

> 日期：2026-08-04 ｜ 子项目 1 ｜ 基底：`gaoxiang12/lightning-lm`（ROS2 Humble）
> 平台：云深处 M20 轮腿机器狗（首要），代码可迁移至足式/轮式机器人

---

## 1. 背景与目标

公司产品项目。以 lightning-lm 为 SLAM 基底，目标是在不重写核心的前提下补强 LIO 前端：

1. **融合腿/轮式里程计**：M20 是轮腿机器人，天然有轮速/腿关节编码器，可作为激光退化时的补充观测源
2. **退化场景鲁棒性**：长走廊、空旷广场等场景激光约束弱，易漂移甚至发散，是现场巡检最常翻车点
3. 为后续子项目 2（定位增强）打地基

**非目标**：不改动激光前端（AA-FasterLIO 的 iVox 配准）；不实现回环/定位的新功能（已存在）；不涉及导航（子项目 3/4）。

## 3. 总体架构

```
┌─────────────────────┐  /joint_states (12腿+4轮)  ┌──────────────────────┐
│ 新包：leg_wheel_odom  │◄──────────────────────────│ M20 SDK / Gazebo     │
│ · 轮式模式：差速运动学  │                          └──────────────────────┘
│ · 腿式模式：接触零速约束 │── 体速度+协方差(50Hz) ──► /odom_wheel
│ · 轮/腿模式检测、打滑检测│     (lightning Odom 格式)
└─────────────────────┘
        │ Odom（含 velocity + 帧间位姿增量）
        ▼
┌────────────────────────────────────────────────────────────┐
│ lightning-lm fork（改动量小）                                  │
│ · wheelspeed_obs_func_ 实现（新写）                           │
│ · LIO 更新触发 Update(WHEEL_SPEED_AND_LIDAR)（接线+修 gap）   │
│ · 退化感知更新（已内置）→ 增强：退化方向/等级发布                │
│ · 定位/回环/2D地图：不动                                       │
└────────────────────────────────────────────────────────────┘
```

**关键决策：轮速观测采用"帧间位姿增量"而非"速度级观测"**。现有 `CustomObservationModel.HTH_` 为 6×6 位姿空间，速度级观测需扩展 ESKF 接口（3×3 速度块，侵入核心）；帧间位姿增量（dx, dy, dθ）的 z/横滚/俯仰行为 0，恰好被内置退化感知机制自动识别为不可观方向处理，**零改动 ESKF 核心**。

## 4. 模块①：腿/轮里程计节点（新包 `leg_wheel_odom`）

- **输入**：`/joint_states`（12 腿关节角/角速度 + 4 轮速）、`/imu`（姿态，腿式模式用）
- **输出**：`/odom_wheel`，body 系线/角速度 + 协方差，50–100Hz，格式对齐 lightning `Odom`

| 模式 | 原理 | 协方差来源 |
|---|---|---|
| 轮式（M20 主用） | 左轮组(fl,hl)+右轮组(fr,hr) 差速 → vx, ωz | 轮半径/轮距误差、打滑度 |
| 腿式（可迁移足式） | 接触检测 → 支撑腿足端零速 → 体速度 = −J(q)·q̇ | 接触质量、关节角噪声 |

- **打滑检测**：轮速反算体速 vs IMU 积分体速一致性偏差 → 超阈值膨胀协方差（协方差缩放原则，不硬切断）
- **模式状态机**：wheel ↔ leg 切换，迟滞 + 切换瞬态协方差膨胀
- **接触检测**（腿式模式）：Gazebo 用关节 effort 阈值；真机 M20 走 SDK 力/电流通道（drdds），接口抽象留扩展
- **错误处理**：joint_states 断线 → 停发并置 invalid，ESKF 自然回退纯 LIO；时间戳对齐复用 lightning `sync.h` 缓冲机制

## 5. 模块②：轮速观测注入 ESKF（fork 内 3 处改动）

1. **实现 `wheelspeed_obs_func_`**（新文件 `core/lio/wheelspeed_obs.cc`）
   - 输入：`/odom_wheel` 帧间位姿增量与协方差
   - 输出：填充 `HTH_`（6×6）/`HTr_`（6×1）；z/横滚/俯仰行置 0
   - 残差 = 轮速位姿增量 ⊖ 状态估计帧间增量；R 阵由模块①协方差动态缩放
2. **修 gap**：`eskf.cc` 的 `WHEEL_SPEED_AND_LIDAR` 分支改为同时调用 lidar + wheelspeed 两个观测函数（累加进同一 `custom_obs_model_`）
3. **接线**：`laser_mapping.cc` LIO 更新处——收到且时间对齐 `odom_wheel` 时 `Update(WHEEL_SPEED_AND_LIDAR)`，否则维持 `Update(LIDAR)`；订阅入口复用 `params.h` 的 `odomTopic`，补进 yaml 配置

**轮足振动考虑**：腿式模式高频振动污染轮速 → 腿式模式下轮速协方差放大（或仅走接触零速约束），在观测函数内实现，不影响核心。

## 6. 模块③：退化感知增强

复用已内置机制（特征值分解 → 掩码剔除 → P 膨胀），增强三点：

1. **退化信息发布**：ESKF 更新时回调暴露退化方向（特征向量）与等级（nullity/秩）→ 轻量话题 `/degeneracy_status`（监控、排障、供子项目 2 使用）
2. **退化时轮速主导**：nullity > 0 时在退化方向上降低轮速观测 R 值——长走廊激光前向约束弱，轮速在走廊轴向（直线差速）恰为最强约束，互补
3. **参数进 yaml**：`degeneracy_threshold_ratio_`、`degeneracy_cov_inflation_` 等补进 `default_robosense.yaml` 的 fasterlio 段

## 7. 错误处理与边界情况

| 故障 | 行为 |
|---|---|
| 轮子打滑/悬空 | 一致性检测 → 协方差膨胀（连续失效置 invalid） |
| joint_states 断线 | 停发 `/odom_wheel`，LIO 回退纯激光 |
| 轮/腿模式切换 | 迟滞状态机 + 瞬态协方差膨胀 |
| 退化误检 | 轮速在退化方向自动接管（兜底，不会更差） |
| 退化+打滑叠加 | 轮速协方差已膨胀 → 接管权重自动受限 |
| 时间戳异常 | `sync.h` 缓冲 + 超时丢弃 |

## 8. 测试与验证

验证环境：M20 Gazebo 仿真（RoboSense 格式点云，ring 字段转换或 `robosense_simulator`）+ 数据集回放 + 真机。

| 场景 | 目的 | 通过标准 |
|---|---|---|
| 长走廊（≥20m，直线+环形） | 退化场景 | 走廊段漂移显著下降（目标 < 原生版 50% 或 < 0.5m/100m） |
| 空旷广场 | 退化场景 | 无发散，轨迹平滑 |
| 办公区（房间+门洞+货架） | 正常场景回归 | ATE 不劣化（差 < 10%） |
| 楼梯/坡道（腿式模式） | 腿式里程计 | 漂移下降，模式切换平滑 |
| 动态人流 | 打滑/遮挡 | 定位不丢失 |

- 基线：原生 lightning-lm vs 改进版，`evo` 计算 ATE/RPE；退化段专项指标 + `/degeneracy_status` 占比统计
- 数据集：lightning-lm 自带 DeepRobotics M20 数据（已适配 RoboSense）离线评测；NCLT 通用性回归
- 真机：M20 走廊/办公区建图 + 定位两模式
- 性能（RK3588）：新增节点 + 观测开销合计 < 0.3 核，不触发 OOM

## 11. 风险与待确认事项

| 风险 | 缓解 |
|---|---|
| `odom_wheel` 帧间增量在打滑严重时引入错误约束 | 协方差动态缩放 + 连续性失效置 invalid |
| 退化方向轮速主导策略在参数上敏感 | 退化+打滑叠加机制限制权重；yaml 参数可调；数据集回归 |
| 腿式模式接触检测在真机不可靠 | 接口抽象 + 轮速协方差放大兜底，腿式模式为可迁移能力而非 M20 首发 |
| M20 真机 SDK 关节数据接口需核实 | 实施阶段先核实 drdds 消息内容与频率 |
| fork 与上游 lightning-lm 的差异维护 | fork 改动集中在 3 处（wheelspeed_obs / eskf gap / laser_mapping 接线），维护面小 |
